# Administration overview

This instance documents how ballware is deployed and operated. It covers the
three operational tracks and their comparison:

- **Local evaluation** — `ballware-docker-compose` (single machine, full stack)
- **Production (Coolify)** — `ballware-backend-coolify`, `ballware-identity-coolify`, `ballware-angular-coolify`
- **Platform infrastructure (k3s)** — `ballware-ansible`

Planned pages: environments comparison, evaluation via Docker Compose,
production on Coolify (backend and identity), production on k3s, backup &
restore, configuration reference (variable names only), and operations
(health checks, upgrades, release process).
