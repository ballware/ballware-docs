# Repositories

These **nine repositories are the documented scope** of this portal. Each
entry reflects the **`main` branch** (state of 2026-11-19), which carries the
current stable versions: the CI pipelines create a `v<SemVer>` git tag for
each main release and publish the matching GHCR image with a `stable` tag.
The newest such tags are listed; where a README is empty, the purpose is
reconstructed from the code and marked as such.[^1]

## Dependency note

The services consume shared `Ballware.Shared.*` NuGet packages (authorization
utils, endpoint mapping, jobs, MCP plumbing). That library repository — like
the production hosting repositories — is **out of scope** for these docs, so
behavior it implements is only described where a documented service evidences
it.

:::caution Status: documentation coverage varies by repo quality
README quality on `main` differs strongly: `ballware-meta-service` (≈290
lines) and `ballware-angular` (≈210 lines) are good; `ballware-storage-service`,
`ballware-generic-service`, and `ballware-ml-service` READMEs are title-only
or near-empty; `ballware-document-service` has **no README at all**. Their
pages here are reconstructed from code and marked where reconstructed.[^1]
:::

## Out of scope for these docs
