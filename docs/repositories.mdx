# Repositories

All repositories of the [ballware GitHub organization](https://github.com/ballware)
that are relevant to the platform. Purposes are sourced from each repo's
README and code layout; where a README is empty, the purpose is reconstructed
from the code and marked as such.

## Platform services

| Repository | Purpose | Main tech |
| --- | --- | --- |
| [ballware-angular](https://github.com/ballware/ballware-angular) | Metadata-driven Angular webclient shell; `@ballware/*` libs (`meta-model`, `meta-api`, `rest-meta-api`, `dx-renderer`, …) | TypeScript / Angular 19, Nx, DevExtreme |
| [ballware-meta-service](https://github.com/ballware/ballware-meta-service) | Stores and serves tenant metadata (entities, pages, lookups, exports, jobs, statistics) | C# / .NET 8, ASP.NET Core, EF Core (Postgres/SQL Server) |
| [ballware-generic-service](https://github.com/ballware/ballware-generic-service) | Generic metadata-driven data engine with REST + MCP endpoints, Jint scripting | C# / .NET 10, Dapper, Quartz |
| [ballware-document-service](https://github.com/ballware/ballware-document-service) | Multi-tenant reporting: XtraReports definitions, Blazor designer/viewer, PDF/e-mail jobs | C# / .NET 10 + DevExpress, Blazor |
| [ballware-storage-service](https://github.com/ballware/ballware-storage-service) | Attachment and temporary file storage (Azure Blob or MinIO) | C# / .NET 8, EF Core |
| [ballware-ml-service](https://github.com/ballware/ballware-ml-service) | ML training/prediction service (AutoML). *Reconstructed — README is content-free* | C# / .NET 8, ML.NET AutoML |
| [ballware-llm-service](https://github.com/ballware/ballware-llm-service) | LLM chat with pgvector RAG, Docling document conversion, MCP tools, SignalR chat | C# / .NET 10, PostgreSQL/pgvector |
| [ballware-apigateway](https://github.com/ballware/ballware-apigateway) | Deny-by-default YARP reverse proxy; the only public API entry | C# / .NET 10, YARP |
| [ballware-shared-dotnet](https://github.com/ballware/ballware-shared-dotnet) | Shared .NET libraries: tenancy, authorization, CRUD mapping, jobs, MCP, OIDC/session auth | C# / .NET 10 |
