# User guide overview

This instance is written for end users and implementers working *with* ballware
applications:

- **Web client** — login/SSO, tenant switching, lists, forms, attachments, import/export, documents, subscriptions, statistics, ML predictions, AI chat
- **Reporting** — report designer and viewer micro-frontends, PDF output, e-mail delivery
- **Metadata authoring** — how entity definitions, page layouts, rights, and scripts are built (the core skill for implementing a ballware application)
- **Applications** — reference examples such as the `ballware-fwpro` catalog
